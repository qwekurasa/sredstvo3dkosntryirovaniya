# Sredstvo 3D — сайт по мотивам референса

Веб-интерфейс с **двумя маленькими белыми карточками**, большим скруглением, обложками гор и раскрывающимися настройками. Название проекта и GitHub-репозитория: `sredstvo3dkosntryirovaniya`.

## Что работает

- Загрузка PNG / JPG / WebP перетаскиванием или кликом на основную карточку.
- При **локальном запуске**: настоящий TRELLIS StableProjectorz в FP16 (используется уже установленная папка с `code/gradio_main.py`), этапы работы, прошедшее время, ориентировочное оставшееся время по истории, экспорт GLB и PLY, история задач и журнал ошибок.
- На **GitHub Pages**: точно такой же интерфейс и предварительный просмотр загруженной картинки, но генерации нет. GitHub Pages не запускает Python и видеокарты. Кнопка честно предлагает открыть локальную студию. Для публичной генерации нужен отдельный GPU-сервер.
- Два SVG-фона входят в проект и работают без интернета. Когда доступен интернет, показываются фотографические обложки с Unsplash.

## Запуск на Windows (настоящая генерация)

1. Распакуй папку проекта отдельно от TRELLIS, например `D:\AI\sredstvo3dkosntryirovaniya`.
2. Убедись, что на ПК есть установленный TRELLIS FP16 и Python 3.11.
3. При необходимости один раз запусти `install.bat`.
4. Запусти `start-local.bat` — откроется `http://127.0.0.1:7867/`.
5. Нажми шестерёнку в карточке, укажи путь к своей папке TRELLIS (например `D:\AI\TRELLIS`) и папку результатов.
6. Нажми на большую карточку, выбери фото, затем «Создать 3D».

*Если порт 7867 занят другой программой, закрой её перед запуском.* Обычный Gradio от TRELLIS лучше закрыть, чтобы освободить VRAM.

На слабых видеокартах (6–8 ГБ VRAM) начни с режима «Экономно» и текстур 512 px. На 6 ГБ успешный запуск не гарантируется. Прогресс по этапам — приблизительный, не точный процент вычислений. Оценка оставшегося времени становится доступна после успешных генераций на конкретном ПК.

## Как разместить сайт на GitHub Pages

1. Создай **публичный репозиторий** `sredstvo3dkosntryirovaniya` на github.com.
2. Загрузи все файлы из этого архива (включая `docs/`) в ветку `main`.
3. В репозитории открой **Settings → Pages**.
4. В **Build and deployment → Source** выбери **Deploy from a branch**. Далее `main` и папку **`/docs`**, нажми Save.
5. Адрес будет `https://ВАШ-ЛОГИН.github.io/sredstvo3dkosntryirovaniya/`.

> На GitHub Pages сайт является интерфейсом/демо. Для настоящей генерации запусти `start-local.bat` на своём компьютере и используй локальный адрес. Перенос интерфейса на GitHub не переносит вычисления TRELLIS на сервер GitHub.

### Собственный домен

`github.io` предоставляется GitHub; отдельный адрес наподобие `sredstvo3dkosntryirovaniya.ru` или `.com` нужно зарегистрировать у регистратора, проверить свободен ли он, и затем подключить в настройках Pages через DNS.

## Структура

- `docs/index.html`, `docs/app.css`, `docs/app.js`, `docs/mountain-*.svg` — сайт, готовый к Pages.
- `app.py` — локальный HTTP-сервер только на `127.0.0.1:7867` (не публичный и не GPU-сервер).
- `worker.py` — запускает функции установленного TRELLIS через его `venv`.
- `install.bat`, `start-local.bat` — локальный запуск на Windows.
- `tests/test_app.py` — автопроверки интерфейса, опций и запуска тестового worker.

### Безопасность

`app.py` слушает только локальный адрес. Не публикуй этот Python-сервер напрямую в интернете и не настраивай проброс порта: он предназначен для твоего ПК. В GitHub не загружай файлы с персональными настройками, модели, токены или `.venv`.

### Проверка

На машине сборки были проверены синтаксис JS/Python, сервер и тестовый worker. Работа с реальной видеокартой и настоящим TRELLIS на твоём ПК отдельно не проверена.
