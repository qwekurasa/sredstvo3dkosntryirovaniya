# Средство 3D — Windows-приложение с локальным TRELLIS

Интерфейс переделан по SVG-макету «Студия · Image → 3D.svg»: три колонки, панель «Исходник», центральный просмотр и настройки справа. **Вместо кувшина — нейтральная заглушка «Загрузить фото».** Никаких текстов о керамике.

## Запуск одной кнопкой

1. Распакуй архив целиком в отдельную папку, например `D:\AI\Sredstvo3D`.
2. Убедись, что у тебя **уже установлен TRELLIS StableProjectorz** с рабочим `code\venv\Scripts\pythonw.exe`. Пример: `D:\AI\TRELLIS`. Закрой старый Gradio, если он запущен.
3. Дважды нажми **`Запустить Средство 3D.cmd`**. Больше **не нужно отдельно запускать `gradio_main.py`, `start-local.bat` или веб-сервер**.
4. Запускатель сам находит Python из установленного TRELLIS, включает локальный HTTP-сервер и открывает окно приложения в Microsoft Edge или Google Chrome в режиме приложения (без вкладок и адресной строки). Используется `127.0.0.1:7867`. Нейросеть запускается автоматически при нажатии **«Создать 3D»**.
5. Один раз при необходимости открой ⚙ вверху справа и укажи папку TRELLIS и папку результатов; дальше пути сохраняются автоматически.

**Наличие установленной модели и её Python-окружения — обязательное условие.** Программа не скачивает повторно веса и не снимает аппаратные ограничения видеокарты.

### Если используешь нестандартный путь

Запускатель читает прошлые настройки из `%LOCALAPPDATA%\TRELLIS-Atelier\settings.json` и проверяет типичные папки `D:\AI\TRELLIS` и `C:\AI\TRELLIS`. Если Python не найден, можно указать нужное окружение в `launch.ps1` либо установить Python 3.11 и запустить ярлык снова. В настройках приложения потом укажи точный путь к TRELLIS.

## Что работает

- Выбор и перетаскивание PNG/JPG/WebP до 24 МБ.
- FP16: реальная генерация через существующий `TRELLIS\code\gradio_main.py` (в отдельном Python-процессе).
- Этапы работы, **точное прошедшее время** и **приблизительное оставшееся** по предыдущим успешным запускам на том же ПК. При первой генерации ETA отсутствует. Полоска показывает этап, не точные проценты нейросети.
- Экономно / Баланс / Детально; текстура, упрощение, seed, шаги и guidance.
- Экспорт GLB, PLY и видео предпросмотра MP4 (видео сохраняется автоматически); скачивание и открытие папки результатов.
- История успешных генераций, отмена процесса, подробные ошибки.
- Информация о GPU/VRAM при наличии `nvidia-smi`.

**Важно:** на видеокартах 6 ГБ может не хватить VRAM даже с FP16. Попробуй режим «Экономно» / 512 px. Отмена завершает отдельный процесс генерации, но не удаляет существующие результаты.

## Это EXE или не EXE?

- **`Запустить Средство 3D.cmd`** — готовый однокликовый запуск на Windows, не требует дополнительного ручного запуска терминала, Gradio или браузерного сервера.
- **`Собрать EXE (по желанию).cmd`** — необязательная автоматическая сборка `dist\Sredstvo3D.exe` на Windows с Python 3.11 и интернетом для установки PyInstaller. После сборки EXE также запускается одним двойным кликом; саму нейросеть в EXE включать не нужно.
- Этот архив не содержит предварительно скомпилированного `.exe`: полноценную Windows-сборку и работу с GPU нужно проверять **на самом Windows-ПК**.

В Windows 10/11 обычно установлен Microsoft Edge. Если Edge/Chrome не найден, приложение откроется в обычном браузере (тогда окно может не закрыть локальный сервер автоматически).

## Код и данные

`desktop.py` — запускает сервер + отдельное окно. `app.py` — локальный HTTP/API (слушает только `127.0.0.1`). `worker.py` — TRELLIS в пользовательском `venv`. `docs/` — адаптивный интерфейс. `tests/` — проверки с тестовой имитацией вычислителя, **не** реальной GPU-моделью.

Личные данные и настройки сохраняются в `%LOCALAPPDATA%\TRELLIS-Atelier`. GitHub Pages может показать только интерфейс, без нейросети. **Не открывай доступ к порту 7867 из интернета и не публикуй в репозитории локальные файлы моделей и историю загрузок.**

## Отладка

- Если программа не открылась, смотри `%LOCALAPPDATA%\Sredstvo3D\launcher.log`.
- Если появится ошибка обработки — нажми ⚙ → «Журнал ошибок».
- Проверь `nvidia-smi` и закрытие другого TRELLIS/Gradio перед запуском.

Проверены синтаксис, HTTP API, механика вызова worker с тестовым движком, верстка и кнопки в Chromium. **Реальная генерация на твоей видеокарте и запуск Windows Edge app-mode здесь не проверялись.**
