# sredstvo3dkosntryirovaniya — интерфейс по вашему макету

Реализация **четырёх SVG-макетов** из присланного `export.zip` в виде настоящего адаптивного веб-интерфейса:

1. **Студия — пусто:** карточка загрузки + примеры оформления + недавние генерации.
2. **Генерация:** этапы, прошедшее время, приблизительное оставшееся время, журнал.
3. **Готово:** GLB/PLY/MP4, 3D/видео-просмотр, параметры запуска.
4. **Параметры:** качество, текстуры, экспорт, seed, пути к TRELLIS.

Сохранены: светлая градиентная палитра, двойной макет, большие округления, минимальная типографика, мягкие тени и маленькие плавающие кнопки. Сайт написан на HTML/CSS/JS, **не состоит из некликабельных SVG-скриншотов**. Для телефона предусмотрена вертикальная верстка.

## Открыть публичный сайт

После публикации GitHub Pages по ветке `main`, папке `/docs`:

https://qwekurasa.github.io/sredstvo3dkosntryirovaniya/

⚠️ **GitHub Pages — статический сайт.** Он показывает дизайн и позволяет выбирать изображение, но не запускает TRELLIS и не обещает генерацию без GPU. Веб-версия честно предлагает открыть локальную студию. Примерные карточки отмечены «Пример интерфейса»; это не результаты пользователя.

## Настоящая генерация на Windows

1. Склонируйте репозиторий или скачайте ZIP, распакуйте например в `D:\AI\sredstvo3dkosntryirovaniya`.
2. Установите Python 3.11 и подготовьте уже работающий TRELLIS StableProjectorz FP16.
3. Запустите `install.bat` один раз и затем `start-local.bat`.
4. Откройте `http://127.0.0.1:7867/`.
5. Во вкладке **Настройки** укажите папку TRELLIS (с `code\gradio_main.py`, `code\venv\Scripts\python.exe`) и путь сохранения результатов; нажмите «Сохранить пути».
6. Загрузите PNG/JPG/WebP (до 24 МБ), установите параметры и нажмите «Создать 3D».

`app.py` слушает **только `127.0.0.1`**; он не предназначен для публикации в интернет. `worker.py` запускает вашу установленную TRELLIS через уже имеющийся Python-venv с `--precision half`. Не запускайте старый Gradio одновременно: это дополнительно расходует VRAM.

Прогресс показывает **этап 1–4**, а не вымышленный процент обработки. Прошедшее время точное; оценка времени до завершения появляется только при наличии предыдущих успешных генераций на этом ПК. Поддерживаются экспорт GLB / PLY и видео-превью MP4. 3D-плеер может потребовать интернет для загрузки `model-viewer`; видео работает локально.

Для 6–8 ГБ видеопамяти начните с пресета «Экономно» (8 шагов, текстуры 512 px), но на 6 ГБ успешная работа не гарантируется.

## Структура

- `docs/index.html` — семантическая разметка четырех экранов и всех интерактивных элементов.
- `docs/app.css` — адаптивная стилизация по SVG-макетам.
- `docs/app.js` — состояния интерфейса, запросы к локальному серверу, файлы, история, таймеры и настройки.
- `app.py`, `worker.py` — предыдущий локальный сервер и вызов реальной TRELLIS FP16. При обновлении дизайна оставлены без изменений.
- `install.bat`, `start-local.bat` — настройка и запуск на Windows.
- `tests/test_app.py` — тесты локальной интеграции с тестовым worker и структуры HTML.

Не публикуйте `.venv`, веса моделей, результаты генераций, персональные настройки и токены. Реальная проверка GPU на компьютере пользователя требуется отдельно.
